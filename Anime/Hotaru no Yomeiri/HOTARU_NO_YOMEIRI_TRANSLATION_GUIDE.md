# CẨM NANG DỊCH THUẬT: HOTARU NO YOMEIRI (FIREFLY WEDDING / HÔN NHÂN ĐOM ĐÓM)

## 1. THÔNG TIN CHUNG
- **Tựa gốc**: ホタルの嫁入り (Hotaru no Yomeiri)
- **Tựa tiếng Anh**: Firefly Wedding
- **Tác giả**: Oreco Tachibana (Tác giả *Promise Cinderella*)
- **Bối cảnh**: Thời kỳ Minh Trị (Meiji Era), Nhật Bản. Phố hoa / hòn đảo biệt lập giam giữ gái làng chơi và tội phạm.
- **Phong cách ngôn ngữ**: Cổ kính, kịch tính, lãng mạn đen tối (Dark Romance / Psychological).

## 4. THUẬT NGỮ ĐẶC TRƯNG
- **Courtesan / Yūjo**: Kỹ nữ / Gái làng chơi.
- **Brothel / Okiya**: Lầu xanh / Nhà chứa / Isekichi.
- **Buy out (身請け - Miuke)**: Chuộc thân / Mua đứt (chuộc kỹ nữ ra khỏi lầu xanh).
- **Superintendent General (警視総監 - Keishi Sōkan)**: Tổng thanh tra Cảnh sát.
- **Count Kirigaya (桐ヶ谷伯爵 - Kirigaya Hakushaku)**: Bá tước Kirigaya.
- **Defective goods (不良品 - Furyōhin)**: Hàng lỗi / Hàng hỏng (cách Nitobe lăng mạ phụ nữ).
