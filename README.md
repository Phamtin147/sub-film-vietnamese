# 🎬 Kho Phụ Đề Việt Ngữ Chuẩn Fansub (Vietnamese Subtitle Archive)

Kho lưu trữ và sao lưu toàn bộ phụ đề phim & anime dịch sang tiếng Việt chất lượng cao theo tiêu chuẩn **Fansub Chuyên Nghiệp**.

- **Biên dịch & Kỹ thuật**: **`Amtia(NOFACE)`**
- **Tiêu chuẩn Typography**: Font Unicode chuẩn **`Segoe UI`**, mã hóa `Encoding: 1`, chuẩn hóa NFC và lưu định dạng **`UTF-8 with BOM`** (ngăn chặn 100% lỗi ô vuông tofu `□`).
- **Cơ chế Auto-load (Zero Disk Bloat)**: Phụ đề rời (`.ass`, `.vie.ass`, `.vie.srt`) cùng tên với video, cho phép **MPC-HC, VLC, PotPlayer, MPV** tự động nhận sub mà không cần chỉnh tay và không làm phình ổ đĩa (0 MB video bloat).

## 🛠️ Hướng dẫn Sử dụng
1. Tải file `.ass` (hoặc `.vie.ass` / `.vie.srt`) tương ứng về máy.
2. Đổi tên file phụ đề trùng khớp 100% với tên file video của bạn.
3. Đặt file phụ đề vào cùng thư mục chứa file video.
4. Mở video bằng **MPC-HC**, **VLC**, **PotPlayer** hoặc **MPV** — Phụ đề tiếng Việt sẽ tự động hiển thị ngay lập tức!
